# Witrack

Premium Windows/macOS desktop time and activity tracking.

**Work smarter. Track clearly.**

Phase 1 delivers a fully functional **Windows** offline-first tracker with a platform-agnostic architecture for future macOS Swift parity.

## Requirements

- Flutter stable with Dart 3.13.7 or later
- Windows 10/11 with Visual Studio 2022 Build Tools (Desktop development with
  C++, ATL for x86/x64, and the Windows SDK)
- Windows Developer Mode enabled (required for Flutter plugin symlinks)
- Optional later: macOS + Xcode for Swift engine work

## Quick start

```bash
flutter pub get
flutter run -d windows
```

## Useful commands

```bash
flutter analyze
flutter test
flutter build windows
```
