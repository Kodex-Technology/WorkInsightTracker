# UI/UX standards

1. One design system — no per-screen one-off palettes.
2. Desktop-first: dense but readable; mouse + keyboard.
3. Clear hierarchy: brand/status → primary action → secondary data.
4. Always show tracking state when a session exists.
5. Loading, empty, error, and permission states are first-class.
6. Dialogs and toasts for desktop (not mobile-sheet defaults).
7. High-DPI / scaling safe layouts; min window ~1080×720 recommended.
8. Accessibility: contrast, focus order, labeled controls.
9. Restrained animation; respect reduced-motion when available.
10. Screenshots and privacy controls must be obvious and reversible.
