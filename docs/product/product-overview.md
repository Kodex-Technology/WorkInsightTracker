# Product overview

**Witrack** is a premium, offline-first desktop time and activity tracking application for Windows and macOS.

## Positioning

Lightweight, reliable, privacy-respecting tracker for individuals and teams who need clear proof of work without hidden surveillance.

Inspired by products such as scrin.io and Apploye for workflow patterns — not for UI or code copying.

## Value

- Explicit start/pause/resume/stop control
- Activity metadata (not keystroke content)
- Foreground application usage
- Configurable screenshots with local encryption
- Idle awareness without silently stopping work
- Real-time local dashboard and reports
- Tray/menu-bar background operation
